# 🎵 Musical World Application

A full-stack web-based music streaming platform developed using PHP and MySQL.  
This application allows users to upload, stream, and manage music collections with a clean and interactive interface.

---

## 🚀 Features

- 🔐 User Registration & Login with Email Verification  
- 🎵 Upload and Stream Songs  
- ❤️ Favorites Management  
- 📂 Playlist Creation  
- 👤 User Profile Management  
- 🛠️ Admin Dashboard (Manage Users & Songs)  

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  

---

## 📁 Project Structure


/admin → Admin panel
/assets → CSS & static files
/config → Database configuration
/includes → Reusable components
/uploads → Songs & images


---

## ⚙️ Setup Instructions

1. Install XAMPP / WAMP  
2. Move project folder to `htdocs`  
3. Import `tables.sql` into phpMyAdmin  
4. Update database credentials in:

/config/db.php

5. Run in browser:

http://localhost/musical-world-project
